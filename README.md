# 🥧 McNamara Pie Company Website

A responsive bakery website developed for **McNamara Pie Company** as a collaborative capstone project. The goal of the project was to design and build a modern website that showcases the bakery's products while providing customers with an intuitive online ordering experience.

> **Status:** Academic capstone project completed.

---

## 📖 Overview

McNamara Pie Company is a responsive website created for a real local business. The project emphasizes clean design, usability, accessibility, and responsive layouts across desktop, tablet, and mobile devices.

The website was designed to serve as the foundation for a production-ready online ordering system.

---

## ✨ Features

- Responsive website design
- Dynamic page sections loaded with JavaScript
- Product showcase
- About section
- Customer testimonials
- Feature highlights
- Interactive order form
- Pie recommendation quiz
- Mobile-friendly navigation
- Social media links
